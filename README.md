## 为什么机房IP看不了TVB：两道检测，第二道才卡人

TVBAnywhere+ 和 myTV SUPER 的检测分两层，机房IP倒在第二层。

第一层是地区识别，IP在香港就行，绝大多数VPN和香港VPS都能过，这层不卡人。第二层是IP类型识别：系统会查IP的ASN（自治系统号），对应数据中心、CDN这类机房服务商的直接拒绝；只有ASN属于香港本地宽带运营商（HGC、iCable这种），才会被当成正常的香港家庭用户放行。

按平台风控的标准，IP大致分三档：

- **机房IP**：AWS、Vultr这类数据中心段，风控直接标红，Netflix版权剧都可能被挡
- **ISP原生IP**：香港本地运营商分配的广播IP，多数平台能过，严格的平台偶尔还是能认出来
- **双ISP住宅IP**：ASN直接显示为家宽运营商，Scamalytics欺诈风险值为0，在风控眼里就是个坐在香港家里看剧的普通人
